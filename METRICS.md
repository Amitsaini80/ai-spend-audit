# METRICS

## Day 1 hypothesis

The likely North Star metric is `qualified audits completed` because the product exists to create useful audits that can also become real Credex leads. Page views alone would overstate success, while booked calls alone would ignore whether the tool itself is being used.

## Input metrics to validate later

- Landing page visitor to audit completion rate
- Audit completion to email capture rate
- High-savings audit to consultation booking rate
